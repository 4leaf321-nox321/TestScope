# 검토함 「규격의 시험 항목」 226건 — 무엇을 먼저 고를까

2026-09-24 개발 DB 실측. 운영에서 화면으로 확정하는 사람을 위한 것이다.

## 왜 지금인가

규격 601건 중 **375건만** 시험 항목에 이어져 있다. 안 이어진 규격은 계열의 시험 항목에
못 붙어서, 「이 시험 되는 장비」 검색에 아무 기여를 못 한다. 226건이 그 답을 기다리는 줄이다.

**새 데이터를 구할 필요가 없다.** 이미 가진 것을 쓰는 일이다.

그리고 2026-09-24 에 규격↔시험 항목이 **N:M** 이 됐다. 한 줄에서 여러 항목을 함께 고를 수
있다 — 전에는 모델이 하나만 담아서 IEC 60529 같은 문서가 방진과 방수 중 한쪽을 잃었다.

## 226건은 한 덩어리가 아니다

| | 건수 | 무엇을 하나 |
| --- | --- | --- |
| **E. 규격이 아니다** | 13 | **고르면 안 된다.** 걷어낸다 |
| **D. 축에 답이 없다** | 6 | 시험 항목을 먼저 더한다 |
| **C. 한 문서가 여럿** | 5 | N:M 으로 여러 개 고른다 |
| **A. 추천이 있다** | 115 | 근거를 보고 확인 |
| **B. 사람이 판단** | 87 | 후보 묶음으로 일괄 |

**결정하면 안 되는 것이 19건(E+D)** 이다. 이걸 모르고 시작하면 없는 규격에 시험 항목을
붙이거나, 없는 답을 억지로 고르게 된다.

---

## E. 규격이 아니다 — 13건, 걷어낸다

```
ISTA · CSA · UL · EN · VDE · ASTM · ISO · DIN · BS
BS template library
ESS (Environmental Stress Screening)
電気用品安全法 (일본 전기용품안전법)
GMIA Bloom test
```

**전부 번호가 없다.** 반입이 장비 카탈로그에서 제정 기관 이름을 규격 번호로 잘못 읽은
것이다(「ASTM 준수」 → 규격 「ASTM」). `BS template library` 는 웹페이지의 메뉴 글자다.

이것들은 시험 항목을 정할 대상이 아니라 **지울 대상**이다. 검토함 `method_cleanup`(44건)이
같은 부류를 다루는 큐다 — 거기서 처리하거나 규격 화면에서 지운다.

**여기에 시험 항목을 붙이면 그 규격이 정상인 것처럼 살아난다.**

## D. 축에 답이 없다 — 6건, 시험 항목을 먼저 더한다

```
IEC 60068-2-1  Test A  (Cold, 저온)          후보: 항온항습(습열) / 온도 사이클
IEC 60068-2-2  Test B  (Dry heat, 고온)      후보: 항온항습(습열) / 온도 사이클
IEC 60068-3-5 · 60068-3-6  (챔버 성능 지침)
MIL-STD-810H Method 502.7  (저온)
```

**후보 중에 맞는 것이 없다.** 시험 항목 축 96개를 훑어보면 「고온 저장」「저온 저장」 같은
**단일 노출** 항목이 아예 없다. 있는 것은 「온도 사이클」「항온항습(습열)」「열충격」 인데,
셋 다 다른 시험이다 — 저온에 24시간 두는 것과 -40↔85 를 500회 왕복하는 것은 장비도 다르고
판정도 다르다.

먼저 할 일: 시험 항목 축에 **「고온 저장(건열)」·「저온 저장」** 을 더한다. 그다음 이 줄들을
거기로 확정한다.

60068-3-5/-3-6 은 시험 방법이 아니라 **챔버 성능을 검증하는 지침**이다. 시험 항목이 없는
것이 맞다 — 「해당 없음」(빈 선택)으로 닫는다.

## C. 한 문서가 여럿 — 5건, 이제 여러 개 고른다

```
MIL-STD-810 Method 501/502/507      → 고온 · 저온 · 습도
MIL-STD-810 Method 514/516          → 진동 · 충격
MIL-STD-202  Method 112 (Seal)      → 기밀
MIL-STD-750  (반도체 전기 시험법)
ASTM D7078   (V-notched rail shear) → 전단
```

N:M 이 되면서 한 줄에서 여러 항목을 체크할 수 있다. **이 5건이 그 첫 사용처다.**

다만 501/502/507 의 「고온·저온」 은 D 와 같은 문제를 만난다 — 축에 값을 먼저 더해야 한다.

---

## A. 추천이 있다 — 115건

추천은 정본(`source/catalog/proposals/*.json`)에서 온다. 근거 유형:

```
규격 제목에 「Tensile」 이 있음          제목 글자
ISO 6508 — 로크웰 경도                  규격 번호를 아는 사람이 적어 둔 것
Wolff-Wilborn 연필 경도 키트가 인용      장비 카탈로그가 함께 적었음
```

**추천은 정답이 아니다.** 첫 보기를 습관적으로 누르게 되므로 근거를 옆에서 읽고 판단한다 —
`followed` 로 추천을 따랐는지가 남아서, 나중에 어느 종류의 추천이 얼마나 틀리는지 셀 수 있다.

## B. 사람이 판단 — 87건, 28묶음

**같은 후보를 받은 줄끼리 묶으면 한 번에 판단할 수 있다.** 큰 묶음 다섯이 45건이다.

### ① 복합재 역학 — 12건 · 후보 [굽힘 / 박리 / 압축 / 전단 / 피로]

| 규격 | 제목이 말하는 것 | 제안 |
| --- | --- | --- |
| ASTM D2344 | Short-Beam **Strength** | **전단** (층간 전단) |
| ASTM D7137 | **Compressive** Residual Strength | 압축 |
| ASTM D6484 | Open-Hole **Compressive** | 압축 |
| ASTM D6671 | Mixed Mode I-II Inter**laminar** Fracture | 박리 |
| ASTM D7249/D7250 | Sandwich **Flexure** | 굽힘 |

제목에 시험 이름이 그대로 들어 있는 부류라 **제목만 읽으면 정해진다.**

### ② 가죽·고무·판재 물성 — 10건 · 후보 [굽힘/내압 파열/박리/압축/인열/전단/천공]

SATRA PM33 · SATRA TM 162 · IUP 8 · ISO 3377-2 · DIN 53331 · EN 310 · BS EN 12390-5 …

SATRA 는 신발·가죽, IUP 는 가죽, EN 310 은 목질 판재다. **제목을 열어야 정해진다** —
후보가 일곱이라 추측이 안 통한다.

### ③ 군용·통신 자격 문서 — 9건 · 후보 [기계적 충격 / 정현·랜덤 진동]

```
MIL-STD-883 · MIL-STD-202 · MIL-STD-331 · MIL-STD-726 · MIL-STD-781
GR-1221 · GR-63-CORE · GR-468  (Telcordia)
```

**이건 단일 시험이 아니다.** MIL-STD-883 은 방법 수십 개(1010 온도 사이클, 2002 기계 충격,
1014 기밀 …)를 담은 **묶음 문서**고, GR-63-CORE 는 NEBS 물리 보호 요건(진동·충격·온도·화재)
이다. 후보 둘 중 하나를 고르면 **문서의 대부분을 버리는 것**이다.

셋 중 하나를 정해야 한다:

1. **번호를 방법 단위로 쪼갠다** — 「MIL-STD-883 Method 1010」 처럼. 가장 정확하지만 규격
   줄이 늘어난다
2. **N:M 으로 여러 항목을 붙인다** — 지금 바로 되지만 「이 규격 = 이 시험」 이 흐려진다
3. **지금은 「해당 없음」 으로 닫는다** — 자격 문서는 시험 항목에 안 붙인다는 결정

**1번을 권한다.** 실무에서 보고서에 인용하는 단위가 방법 번호이기 때문이다.

### ④ 고무 경도 — 9건 · 후보 [IRHD 경도 / 쇼어 경도]

| 규격 | 근거 | 제안 |
| --- | --- | --- |
| DIN ISO 48-3 · 48-9 · DIN EN 59 | **ISO 48 이 IRHD 규격 그 자체** | IRHD 경도 |
| JIS K 6253 | 듀로미터와 IRHD 를 **둘 다** 규정 | **둘 다** (N:M) |
| ASTM D2583 | Barcol 경도 — 후보에 없음 | 「해당 없음」 또는 축에 추가 |

### ⑤ 플라스틱·금속 경도 — 5건 · 후보 [누프/로크웰/브리넬/비커스]

ISO 2039-1 은 **볼 압입(Ball indentation)** 경도라 후보 넷 중 어느 것도 아니다 —
브리넬과 원리가 비슷하지만 다른 시험이다. VDI/VDE 2616-1 은 경도 시험기 **검증 지침**이다.

**이 묶음은 「해당 없음」 이 많이 나올 자리다.**

---

## 순서

1. **E 13건을 걷어낸다** — 5분. 이걸 먼저 안 하면 나머지를 세는 숫자가 계속 틀린다
2. **시험 항목 축에 「고온 저장」·「저온 저장」 을 더한다** — D 6건 + C 일부가 풀린다
3. **B 의 ①④ 21건** — 제목·번호로 정해지는 것. 표를 보고 그대로
4. **A 115건** — 추천을 근거와 대조. 가장 양이 많고 가장 빠르다
5. **B 의 ③ 9건** — 자격 문서를 어떻게 다룰지 결정한 뒤에
6. **B 의 ②⑤ 15건 + 나머지** — 제목을 열어 봐야 하는 것

1·2 를 먼저 하는 이유: **그 19건은 답이 「고르지 않는 것」** 이라, 섞여 있으면 판단이
계속 막힌다.

## 남는 물음

- 시험 항목 축에 없는 것이 더 있다: **Barcol 경도 · 볼 압입 경도 · 기밀(seal)**. 고를 때마다
  하나씩 나올 것이다 — 「해당 없음」 으로 닫고 나중에 축을 손보거나, 그때그때 값을 더한다
- 자격 문서(MIL-STD-883 · GR-63-CORE)를 방법 단위로 쪼개면 규격이 601 → 700 대가 된다.
  그 결정이 이 큐 밖의 일이다
