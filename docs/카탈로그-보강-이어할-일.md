## 1. OpenAlex 빈 것 채우기 — 2026-09-14 09:00 이후

OpenAlex(openalex.org — 학술 논문 메타데이터 공개 API, Claude 와 무관한 외부 서비스)는 키 없이 하루
요청 예산이 있어 278 객체 중 95 만 받고 막혔다. 예산은 UTC 자정(한국 09:00)에 풀린다.

    cd source/catalog_extension
    python tools_harvest_papers.py --fill-openalex     # count 가 null 인 객체만 다시 (예산에 걸리면 멈춘다)
    python tools_propose.py                            # 후보를 다시 세운다 (decided 는 보존)
    cd ../../backend && python scripts/refresh_review.py   # 검토함에 반영 (화면의 「다시 세우기」 와 같다)

하루에 다 안 되면 다음 날 같은 명령을 또 돌린다 — 이미 받은 것은 건너뛴다.

2. 확정된 것은 DB 에 바로 붙는다. `backend/scripts/export_review.py` 로 정본
   `source/catalog/proposals/series_*.json` 의 `decided` 에 되돌려 쓴다 → 운영 반입 때 자동 적용.
3. 규격이 붙으면 「규격의 시험 항목」 물음이 늘 수 있다(시험이 여럿인 계열에 붙은 규격) — 같이 처리.
