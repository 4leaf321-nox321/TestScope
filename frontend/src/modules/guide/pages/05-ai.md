# AI 도구 연결

Claude, Codex, Gemini 등 AI 도구를 MCP로 연결하면 장비와 시험의 조회, 입력을 AI 도구에서 수행할 수 있음. 연결 설정은 [내 정보](/me)의 ‘AI 도구에 등록하기’에서 도구별로 생성됨(토큰 포함).

## 토큰

- 공용 자격 없음. 사용자별 개인 토큰으로 연결함.
- 토큰의 권한은 발급한 사용자의 권한을 초과하지 않음.
- 범위는 발급 시 선택하며 이후 확대 불가(재발급 필요). 기본값은 읽기 전용임.

| 범위              | 대상                                                            |
| ----------------- | --------------------------------------------------------------- |
| `read`            | 모든 조회, 검색                                                 |
| `catalog:write`   | 계열, 기종, 사양 정의, 규격, 온톨로지, 시험 항목 축, 속성 정의  |
| `equipment:write` | 보유 장비, 장비 시험 항목, 교정, 신뢰성 시험, 사내 규격서, 첨부 |

계정, 부서, 부서 멤버, 토큰, 공지, 서버 설정은 토큰으로 변경 불가(화면 전용).

## AI 입력 데이터의 처리

| 대상                    | 처리                                                        |
| ----------------------- | ----------------------------------------------------------- |
| 신뢰성 시험             | 후보로 등록됨. 담당자 확인 후 목록에 표시                   |
| 확정된 신뢰성 시험      | 수정, 삭제 불가                                             |
| 기종 사양               | 빈 칸 입력 가능. 사람이 입력한 값은 사용자 확인 후에만 변경 |
| 삭제                    | 대상 확인 후 실행. AI 도구가 대상을 먼저 제시함             |
| 온톨로지 이름 변경·병합 | 시스템 관리자 자격 필요                                     |

## 변경 기록

모든 변경에 경로(화면 또는 MCP)와 토큰 이름이 기록됨. 토큰 이름은 용도를 알 수 있도록 지정 권장.

역할별 사용 범위는 [권한](/guide/permissions) 참조.
