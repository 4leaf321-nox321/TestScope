# AI 도구 연결

Claude, Codex, Gemini 등 AI 도구를 MCP로 연결하면 장비와 시험의 조회, 입력을 AI 도구에서 수행할 수 있음. 연결 설정은 [내 정보](/me)의 ‘AI 도구에 등록하기’에서 도구별로 생성됨(토큰 포함).

## 토큰

- 공용 자격 없음. 사용자별 개인 토큰으로 연결함.
- 토큰의 권한은 발급한 사용자의 권한을 초과하지 않음.
- 범위는 발급 시 선택하며 이후 확대 불가(재발급 필요). 기본값은 읽기 전용임.

| 범위              | 대상                                                            |
| ----------------- | --------------------------------------------------------------- |
| `read`            | 모든 조회, 검색                                                 |
| `catalog:write`   | 계열, 기종, 사양 정의, 규격, 온톨로지, 시험 항목 축, 속성 정의  |
| `equipment:write` | 보유 장비, 장비 시험 항목, 교정, 신뢰성 시험, 사내 규격서, 첨부 |
| `admin:write`     | 계정, 부서, 부서 멤버, 공지, 허브 연계, VOC (확인 창 필수)      |

토큰 발급·폐기, 비밀번호, 허브 토큰은 토큰으로 변경 불가(화면 전용 — 평문 비밀이 AI 대화에 남지 않게).

## 확인 창

신뢰성 시험 확정·반려·다시 후보로, 확정된 시험 수정, 일괄 삭제, 규격 병합, 관리 작업처럼 사람이 정할 일은 AI 도구가 실행하기 전에 **확인 창**을 띄움. 창에 바뀌는 내용(시험 이름과 칸마다의 값, 건수, 사유)이 실리고, 사용자가 수락해야 실행됨. 거절하면 실행되지 않음.

- 확인 창(MCP elicitation)을 띄울 수 있는 AI 도구에서만 가능함(예: Claude Code). 띄울 수 없는 도구에서는 실행되지 않음.
- 수락한 변경은 변경 이력에 ‘MCP · 사용자 확인’으로 남음.

## AI 입력 데이터의 처리

| 대상                    | 처리                                                                        |
| ----------------------- | --------------------------------------------------------------------------- |
| 신뢰성 시험             | 후보로 등록됨. 담당자 확인 후 목록에 표시                                   |
| 확정된 신뢰성 시험      | 확인 창에서 사용자가 수락한 경우에만 수정, 삭제                             |
| 기종 사양               | 빈 칸 입력 가능. 사람이 입력한 값은 사용자 확인 후에만 변경                 |
| 삭제                    | 대상 확인 후 실행. AI 도구가 대상을 먼저 제시함                             |
| 온톨로지 이름 변경·병합 | 시스템 관리자 자격 필요                                                     |
| 검토함 확정             | 시스템 관리자 자격 필요. 사용자 지시 후 실행, 결정자는 ‘이름(MCP)’으로 기록 |

## 변경 기록

모든 변경에 경로(화면, MCP, MCP · 사용자 확인)와 토큰 이름이 기록됨. 토큰 이름은 용도를 알 수 있도록 지정 권장.

역할별 사용 범위는 [권한](/guide/permissions) 참조.
