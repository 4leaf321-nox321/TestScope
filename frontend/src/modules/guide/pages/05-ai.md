# AI 에 붙여 쓰기

Claude·Codex·Gemini 같은 도구를 이 플랫폼에 붙이면 그 도구가 장비와 시험을 **직접
찾고 채운다.** 설정은 **[내 정보](/me)** 의 「AI 도구에 등록하기」 가 도구별로
만들어 준다 — 토큰까지 채워서 나오므로 복사만 하면 된다.

## 권한은 **붙인 토큰의 것**이다

공용 자격이 없다. 쓰는 사람 수만큼 연결이 생겨도 각자 자기 권한으로 본다. 그리고
**토큰은 그 사람을 넘지 못한다** — 화면에서 못 하던 일은 토큰으로도 안 된다.

범위는 발급할 때 고르고 **나중에 넓힐 수 없다**(새로 발급해야 한다). 기본은 읽기
전용이고, 그것만으로 찾기·검색·조회가 다 된다.

## AI 가 쓴 것은 바로 쓰이지 않는다

|                           |                                                                     |
| ------------------------- | ------------------------------------------------------------------- |
| 신뢰성 시험               | **후보**로 선다. 사람이 확인해야 목록에 뜬다                        |
| 확정된 시험               | 기계 자격으로 **못 고친다**                                         |
| 기종 사양                 | 빈 자리는 채운다. **값이 있는 자리는 거절**하고 지금 값을 보여 준다 |
| 온톨로지 이름 고치기·병합 | 범위가 아니라 **자격**이 막는다                                     |

마지막 줄이 중요하다. 사양의 값이 이미 있으면 AI 는 그것을 **조용히 못 덮는다** — 사람이
운영에서 고쳐 둔 값일 수 있기 때문이다. 그때 AI 는 지금 값을 들고 와서 묻는다:
「사양서에는 300 kN 인데 지금 30 kN 으로 들어가 있습니다. 어느 쪽입니까」.

## 무엇이 들어왔는지는 남는다

변경마다 **통로**(화면인가 MCP 인가)와 **토큰 이름**이 기록된다. 소유자만 남기면 사람이
넣은 것과 AI 가 넣은 것이 구별되지 않는다. 그래서 토큰 이름을 용도로 적어 두면 나중에
되짚을 수 있다.
