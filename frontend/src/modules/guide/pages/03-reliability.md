# 신뢰성 시험

신뢰성 시험은 사업부별 사내 시험 절차임. 시험 항목(예: 항온항습)이 공통 분류라면, 신뢰성 시험은 해당 분류를 적용하는 사내 절차에 해당함.

## 식별 기준

    사업부 + 이름 + 적용군 + 판(규격서 개정)

- 같은 규격서의 개정판은 각각 별도로 등록됨(예: 개정 14, 개정 18).
- 목록은 기본적으로 최신판만 표시함. ‘과거 판 포함’ 선택 시 이전 판도 표시됨.

## 시험 조건 입력

- 시험 조건은 속성 칸(온도, 습도, 전압, 가속도 등)에 숫자로 입력. 목적 칸의 서술은 장비 판정에 사용되지 않음.
- 숫자로 표현할 수 없는 조건은 비고에 입력(예: 상온). 하한만 있는 조건은 최솟값만 입력(예: 85 이상).
- 같은 조건이 여러 벌이면 묶음 지정(예: 동작 −15~~45 ℃, 저장 −40~~25 ℃). 묶음 미지정 시 한 줄만 저장됨.

## 원문 근거

| 칸              | 내용                  |
| --------------- | --------------------- |
| 비고            | 입력자의 해석         |
| 원문            | 문서 기재 내용 그대로 |
| 환산 전 값·단위 | 예: `158`, `degF`     |

단위를 환산한 경우 환산 전 값과 단위를 함께 기록함.

## 후보와 확정

- 개인 토큰 또는 MCP로 등록된 시험은 ‘후보’ 상태로 등록되며, 담당자 확인 후 ‘확정’ 상태가 됨. 확인은 화면에서, 또는 AI 도구의 확인 창에서 내용을 보고 수락하는 것으로 함.
- 전사 목록에는 확정된 시험만 표시됨.
- 확정된 시험을 MCP로 수정, 삭제하려면 AI 도구의 확인 창에서 사용자가 수락해야 함. 화면에서는 ‘다시 후보로’ 실행 후 수정(목록에서 여러 건 선택 가능).

## 권한

| 작업                  | 부서 멤버 | 부서 관리자      | 시스템 관리자 |
| --------------------- | --------- | ---------------- | ------------- |
| 조회                  | 가능      | 가능             | 가능          |
| 등록·수정·삭제        | 불가      | 소속 사업부 시험 | 전체          |
| 확인·반려·다시 후보로 | 불가      | 소속 사업부 시험 | 전체          |
| 시험 항목 요청 결정   | 불가      | 불가             | 가능          |

- 부서 관리자의 권한 범위는 해당 부서가 속한 사업부의 시험임.
- 확인, 반려, 다시 후보로는 화면에서, 또는 MCP의 확인 창(사용자 수락)으로 수행함. 역할별 MCP 사용 범위는 [권한](/guide/permissions) 참조.

## 수행 가능 현황

[수행 가능 현황](/reliability-tests/coverage)은 확정된 최신판 신뢰성 시험마다 지금 돌릴 수 있는 장비 수를 보여 줌. 전사 목록과 사업부 화면의 ‘수행 가능 현황’ 단추로 이동.

- 돌릴 수 있음: 시험 조건이 장비 범위에 모두 들고, 가동 상태(고장·점검·폐기 제외)이며, 교정이 유효한 장비. ‘되는 장비’ 창과 같은 판정에 교정을 더한 것임.
- 확인 필요: 장비에 그 조건이 안 적혀 있거나, 교정 대상인데 이력이 없는 장비. 돌릴 수 있음으로 세지 않음.
- 교정 만료: 차기 교정일이 지난 장비. 빼고 셈.
- 교정 임박: 돌릴 수 있음 중 60일 안에 교정이 끝나는 장비.
- 장비는 사업부로 좁히지 않음(옆 사업부 장비도 대여 가능). 괄호 안 수는 시험 사업부 소유 장비.

시험의 상태는 장비 수가 가장 적은 시험 항목(병목)이 정함.

| 상태      | 뜻                                           |
| --------- | -------------------------------------------- |
| 불가      | 돌릴 장비 0대                                |
| 확인 필요 | 0대이나 조건 미기재·교정 이력 없는 장비 있음 |
| 1대뿐     | 그 장비가 서면 시험 중단                     |
| 교정 임박 | 교정이 곧 끝나는 장비가 빠지면 1대 이하      |
| 항목 없음 | 시험 항목이 지정되지 않아 셀 수 없음         |
| 여유      | 2대 이상                                     |

조건 묶음이 여럿인 시험은 모든 묶음을 한꺼번에 만족하는 장비로 셈(예외 경로까지 돌릴 장비).

## 근거 규격이 대체되면

- 참조 규격이 ‘대체됨’(새 판으로 개정)이 되면, 그 옛 판을 근거로 하는 신뢰성 시험과 장비 시험 항목이 시험법·규격 화면의 ‘대체된 규격 참조’에 표시됨.
- 홈 ‘남은 일’에 건수가 표시되고(시스템 관리자, 해당 사업부·부서 관리자), 관리자에게 규격마다 한 번 알림이 감.
- 새 판으로 고치면 목록에서 빠짐. 신뢰성 시험은 사업부 화면에서, 장비는 장비 화면의 시험 항목에서 규격 변경.

## 등록·수정 위치

[전사 목록](/reliability-tests)은 부서 간 비교와 조회용임. 등록과 수정은 부서 화면에서 수행하며, 목록에서 부서 이름 선택 시 해당 부서 화면으로 이동함.
