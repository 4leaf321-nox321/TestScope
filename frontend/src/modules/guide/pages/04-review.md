# 못 고르는 쪽에 말할 자리 — 검토함과 제안

카탈로그와 온톨로지는 시스템 관리자만 고친다. 그런데 **막힌 사람이 아무 말도 못 하면**
그 자리는 영영 안 채워진다. 그래서 길을 셋 둔다.

| 자리                    | 누가                              | 무엇을                                                     |
| ----------------------- | --------------------------------- | ---------------------------------------------------------- |
| [검토함](/admin/review) | 누구나 의견, 확정은 시스템 관리자 | 반입이 못 정한 것 — 어느 시험의 규격인가, 무슨 조건을 묻나 |
| 시험 항목 제안          | 누구나                            | 「이 장비가 하는 시험이 목록에 없다」                      |
| 기종 등록 요청          | 누구나                            | 「이 기종이 카탈로그에 없다」                              |

**검토함이 「관리」 가 아니라 「공통」 에 있는 이유**: 의견은 로그인한 누구나 낸다(데이터를
안 건드린다). 확정만 시스템 관리자가 한다. 도메인을 아는 사람이 관리자일 이유가 없다.

## 제안은 **모여서** 한 번에 풀린다

같은 말끼리 모이고, 관리자가 한 번 정하면 **요청한 장비·시험에 한꺼번에 걸린다.**
관리자가 항목을 세우고 나서 하나씩 다시 열어 고르게 하면 그 일이 밀리고, 밀리면 요청은
남았는데 대상은 여전히 미연결인 상태가 된다.

## 열린 축과 닫힌 축

값을 **더하는** 것과 **고치는** 것이 다르다. 더하는 것은 늘어날 뿐이라 나중에 병합으로
풀 수 있지만, 이름을 고치는 것은 그 값을 쓰는 **모든 화면의 글자**를 바꾸는 일이라
되돌릴 자리가 감사 기록뿐이다.

- **열린 축**(제조사·거점·장비유형 …) — 누구나 값을 더한다
- **닫힌 축**(시험 항목 …) — 관리자만. 그래서 제안으로 받는다
- **이름 고치기·병합·축 만들기** — 언제나 시스템 관리자

## 403 을 받았을 때 — 막는 자리가 둘이다

| 코드             | 뜻                          | 할 일                              |
| ---------------- | --------------------------- | ---------------------------------- |
| `TSC-AUTH-0106`  | 토큰에 **범위**가 없다      | 토큰을 다시 발급하면 된다          |
| `TSC-AUTH-0103`  | 이 사람에게 **자격**이 없다 | 다시 발급해도 소용없다. 관리자에게 |
| `TSC-VOCAB-0002` | **닫힌 축**이다             | 그 축은 관리자만 값을 더한다       |

범위를 아무리 넓혀도 사람의 자격은 안 넓어진다. 셋 다 403 이라 사람은 대개 토큰을
다시 만들러 가는데, 둘은 그래도 안 된다.
