# 권한

역할은 부서 멤버, 부서 관리자, 시스템 관리자의 세 가지임. MCP로 연결한 AI 도구는 연결한 사용자의 역할 범위 안에서 화면과 같은 작업을 수행함. 사람의 판단이 필요한 작업은 AI 화면의 **확인 창**에서 사용자가 수락해야 실행됨.

표기: 화면·MCP(화면과 MCP 모두 가능), 화면·MCP(확인)(MCP는 AI 화면의 확인 창에서 수락 후 실행), 화면(화면에서만 가능), MCP(MCP에서만 가능), 불가(권한 없음).

## 신뢰성 시험

| 작업                    | 부서 멤버 | 부서 관리자                 | 시스템 관리자  |
| ----------------------- | --------- | --------------------------- | -------------- |
| 조회, 검색              | 화면·MCP  | 화면·MCP                    | 화면·MCP       |
| 등록, 수정              | 불가      | 화면·MCP(소속 사업부)       | 화면·MCP       |
| 삭제                    | 불가      | 화면·MCP(소속 사업부)       | 화면·MCP       |
| 확인, 반려, 다시 후보로 | 불가      | 화면·MCP(확인)(소속 사업부) | 화면·MCP(확인) |
| 일괄 처리               | 불가      | 화면·MCP(확인)(소속 사업부) | 화면·MCP(확인) |
| 시험 항목 요청 등록     | 불가      | MCP(소속 사업부)            | MCP            |
| 시험 항목 요청 결정     | 불가      | 불가                        | 화면·MCP       |

- MCP로 등록한 시험은 후보 상태로 등록됨.
- MCP로 확정된 시험을 수정·삭제하거나 확정·반려·다시 후보로 하려면 AI 화면의 확인 창에서 사용자가 내용을 보고 수락해야 함.

## AI 화면의 확인 창을 거치는 작업

- 신뢰성 시험의 확인, 반려, 다시 후보로, 검토 완료 개정 지정, 확정된 시험의 수정·삭제
- 일괄 작업(장비 일괄 삭제, 신뢰성 시험 일괄 처리) — 묶음마다 한 번
- 규격 병합, 규격의 시험 항목 해제, 검토함 MCP 의견대로 일괄 확정
- 계정(승인, 거절, 정지, 소속, 시스템 관리자 지정), 부서, 부서 멤버, 공지, 허브 연계, VOC 관리 — 토큰에 `admin:write` 범위 필요

확인 창에는 바뀌는 내용(시험 이름과 칸마다의 값, 건수, 사유)이 실림. 거절하면 실행되지 않음. 수락한 변경은 변경 이력에 ‘MCP · 사용자 확인’으로 남음. 확인 창을 띄울 수 없는 AI 도구에서는 이 작업들이 실행되지 않음.

## 화면 전용 작업

- 토큰 발급·폐기, 계정 만들기·비밀번호 초기화(임시 비밀번호), 허브 토큰 입력 — 평문 비밀이 AI 대화 기록에 남지 않게

## MCP 사용 시 확인 사항

- 필요한 토큰 범위: 조회는 `read`, 카탈로그·온톨로지·규격 변경은 `catalog:write`, 장비·신뢰성 시험·사내 규격서 변경은 `equipment:write`, 계정·부서·공지·허브 연계는 `admin:write`.
- 토큰의 권한은 발급한 사용자의 역할을 초과하지 않음.
- 삭제는 AI 도구가 삭제 대상을 먼저 제시하고, 사용자 확인 후 실행됨.
- 검토함 확정은 사용자가 대상과 선택을 지시한 경우에만 실행됨. 결정자·의견·보류한 사람은 ‘이름(MCP)’으로 기록됨.
- 403 오류 시 오류 코드로 원인 확인: `TSC-AUTH-0106`(토큰 범위 없음), `TSC-AUTH-0103`(계정 자격 없음), `TSC-WORKSPACES-0003`(부서 관리자 전용), `TSC-AUTH-0108`(확인 증표 불일치 — MCP 서버와 백엔드 설정 확인).
