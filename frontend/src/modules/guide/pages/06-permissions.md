# 권한

역할은 부서 멤버, 부서 관리자, 시스템 관리자의 세 가지임. MCP로 연결한 AI 도구는 연결한 사용자의 역할 범위 안에서 화면과 같은 작업을 수행함. 사람의 판단이 필요한 일부 작업은 화면 전용임.

표기: 화면·MCP(화면과 MCP 모두 가능), 화면(화면에서만 가능), MCP(MCP에서만 가능), 불가(권한 없음).

## 신뢰성 시험

| 작업                    | 부서 멤버 | 부서 관리자           | 시스템 관리자 |
| ----------------------- | --------- | --------------------- | ------------- |
| 조회, 검색              | 화면·MCP  | 화면·MCP              | 화면·MCP      |
| 등록, 수정              | 불가      | 화면·MCP(소속 사업부) | 화면·MCP      |
| 삭제                    | 불가      | 화면·MCP(소속 사업부) | 화면·MCP      |
| 확인, 반려, 다시 후보로 | 불가      | 화면(소속 사업부)     | 화면          |
| 일괄 처리               | 불가      | 화면(소속 사업부)     | 화면          |
| 시험 항목 요청 등록     | 불가      | MCP(소속 사업부)      | MCP           |
| 시험 항목 요청 결정     | 불가      | 불가                  | 화면·MCP      |

- MCP로 등록한 시험은 후보 상태로 등록됨.
- MCP는 확정된 시험을 수정, 삭제할 수 없음. 수정이 필요한 경우 화면에서 ‘다시 후보로’ 실행 후 진행.

## 화면 전용 작업

- 신뢰성 시험의 확인, 반려, 다시 후보로, 검토 완료 개정 지정
- 검토함 의견, 확정
- 일괄 작업(장비 일괄 삭제, 신뢰성 시험 일괄 처리)
- 계정, 부서, 부서 멤버, 토큰, 공지, 서버 설정 관리

## MCP 사용 시 확인 사항

- 필요한 토큰 범위: 조회는 `read`, 카탈로그·온톨로지·규격 변경은 `catalog:write`, 장비·신뢰성 시험·사내 규격서 변경은 `equipment:write`.
- 토큰의 권한은 발급한 사용자의 역할을 초과하지 않음.
- 삭제는 AI 도구가 삭제 대상을 먼저 제시하고, 사용자 확인 후 실행됨.
- 403 오류 시 오류 코드로 원인 확인: `TSC-AUTH-0106`(토큰 범위 없음), `TSC-AUTH-0103`(계정 자격 없음), `TSC-WORKSPACES-0003`(부서 관리자 전용).
