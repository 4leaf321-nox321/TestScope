# 장비 등록

## 필수 항목

자산번호, 장비명, 보유 부서, 거점, 상세 위치, 장비 분류.

- 장비 분류는 기종 선택 시 해당 계열의 분류로 자동 지정됨.
- 기종을 선택하지 않은 경우 분류를 직접 선택해야 함. 기종과 분류가 모두 없으면 등록 불가.
- 분류가 없는 장비는 분류 기준 조회 화면에서 누락됨.

## 기종이 카탈로그에 없는 경우

- 유사 기종 선택 금지. 다른 기종의 하중, 온도 사양이 해당 장비의 판정에 사용됨.
- 기종을 비워 두고 ‘기종 등록 요청’ 작성(제조사, 모델명 입력).
- 동일 요청은 하나로 묶임. 시스템 관리자가 기종을 등록하면 요청한 장비가 일괄 연결됨.
- 미연결 장비는 [보유 장비](/equipment) 목록의 ‘카탈로그 미연결’에서 확인 가능.

## 장비 상태

| 코드          | 상태         | 검색 포함 여부 |
| ------------- | ------------ | -------------- |
| `operational` | 가동         | 포함           |
| `idle`        | 미사용       | 포함           |
| `stopped`     | 미가동       | 포함           |
| `unknown`     | 미기재       | 포함           |
| `maintenance` | 점검·교정    | 제외           |
| `repair`      | 고장 수리 중 | 제외           |
| `incoming`    | 입고         | 제외           |
| `retired`     | 폐기         | 제외           |
| `struck`      | 취소선       | 제외           |

- 미사용, 미기재 장비는 사용 가능 장비로 간주하여 검색에 포함함.
- 상태 변경 시 사유 입력(예: 제어보드 고장, 부품 대기). 상태가 다시 변경되면 이전 사유는 자동 삭제됨.

## 담당자

- 장비별 연락 담당자 지정. 다른 부서 소속 사용자도 지정 가능. 휴면 계정은 지정 불가.
- 여러 장비의 담당자는 대장 반입의 ‘담당자’ 열에 이메일로 일괄 입력. 동일 이름이 여러 명이면 자동 지정 없이 오류로 표시됨.

## 권한

| 작업                      | 부서 멤버 | 부서 관리자 | 시스템 관리자 |
| ------------------------- | --------- | ----------- | ------------- |
| 장비 등록·수정, 대장 반입 | 가능      | 가능        | 가능          |
| 시험 항목·조건·실측 입력  | 가능      | 가능        | 가능          |
| 교정 이력 입력            | 가능      | 가능        | 가능          |
| 장비 삭제                 | 불가      | 가능        | 가능          |

- 부서 멤버와 부서 관리자의 권한은 소속 부서 장비에 한함.
- 삭제된 장비는 목록에서 제외되나 기록은 보존됨.
- 역할별 MCP 사용 범위는 [권한](/guide/permissions) 참조.

## 기종 사양과 장비 실측

| 구분      | 내용                                      |
| --------- | ----------------------------------------- |
| 기종 사양 | 해당 기종 전체 장비의 기준값(제조사 사양) |
| 장비 실측 | 해당 장비 1대의 측정값                    |

- 개별 장비의 측정값은 기종 사양이 아닌 장비 실측에 입력.
- 실측값은 기종 사양을 대체하지 않고 우선 적용됨. 상세 화면에 두 값이 함께 표시됨.
- 실측값 입력 시 측정일 입력 필요.
