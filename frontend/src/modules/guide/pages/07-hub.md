# 허브 기준정보

기준정보 허브(StandardPlatform)는 개발모델 · 과제 · 프로젝트 · 시험 주체 같은 **플랫폼 공통 기준정보**의 정본임. TestScope는 허브의 공개 기준정보를 매일 야간에 받아 [허브 기준정보](/hub)에 표시함.

## 받은 데이터

- 타입마다 온톨로지 축 하나(`hub_<타입>`), 객체마다 값 하나로 반영됨. 값의 코드가 허브 식별자임.
- **TestScope에서 수정 불가.** 이름 · 값 추가 · 별칭 · 병합은 허브에서 하고, 다음 수신에 반영됨.
- 허브에서 삭제 · 사용 중지 · 병합된 객체는 지워지지 않고 ‘사용 중지’로 남음. 병합된 객체를 가리키던 시험 · 장비는 통합 대상으로 옮겨짐.
- 식별자가 바뀐 객체는 같은 값으로 유지되고, 옛 식별자는 별칭으로 남아 옛 식별자로도 찾을 수 있음.

## 시험 · 장비에 연결

- 신뢰성 시험 · 장비의 ‘값 고르기’ 칸 중 허브 축을 가리키는 칸(예: 대상 개발모델)에서 선택함. 칸은 시스템 관리자가 속성 정의에서 만듦.
- 운영에서는 MCP로 연결함. **확정된 신뢰성 시험에도 허브 칸만은** MCP로 붙이고 뗄 수 있음(다른 칸은 AI 도구의 확인 창에서 사용자 수락 필요). 변경 이력에 남음.

## 관리 (시스템 관리자)

- 관리 › 허브 연계에서 허브 주소 · 토큰 · 받을 타입 · 야간 시각을 설정함. 토큰은 저장 후 다시 표시되지 않음. 토큰 외의 설정과 수동 수신은 MCP로도 가능(확인 창에서 수락 후).
- 수신 현황(타입별 허브 수 · 사용 중 수 · 기준 시각 · 결과)과 수신 이력(실행별 변경 건수 · 오류 · request_id)을 봄.
- 수신 실패와 허브 구조 변경은 알림과 홈 ‘남은 일’로 알려짐.
