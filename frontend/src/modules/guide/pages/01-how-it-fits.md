# 구조 개요

TestScope는 카탈로그와 사내 운영의 두 영역으로 구성됨.

| 구분      | 카탈로그              | 사내 운영                       |
| --------- | --------------------- | ------------------------------- |
| 대상      | 시판 장비와 시험 체계 | 사내 보유 장비와 수행 절차      |
| 예시      | Instron 68FM-300 기종 | 3동 201호에 설치된 68FM-300 1대 |
| 소유      | 전사 공용             | 부서                            |
| 수정 권한 | 시스템 관리자         | 부서 멤버(삭제는 부서 관리자)   |

카탈로그 수정은 시스템 관리자로 한정됨. 기종 사양은 해당 기종을 사용하는 모든 부서의 검색 결과에 반영됨.

## 장비 구조

```
계열 (Instron 6800 시리즈)          시험 항목, 제조사
  └ 기종 (68FM-300)                 하중, 온도 등 수치 사양
      └ 보유 장비 (자산번호 A-102)    설치 위치, 상태, 담당자
```

- 보유 장비는 계열이 아닌 기종에 연결함. 같은 계열 안에서도 사양 차이가 큼(예: Instron 5900 계열의 하중 용량 0.5~600 kN).
- 장비 등록 시 계열의 시험 항목과 기종의 사양이 장비로 복사됨.
- 등록 이후 기종 사양을 수정해도 기존 장비의 값은 변경되지 않음. 저장 시 영향 대수가 표시됨.

## 시험 구조

```
신뢰성 시험 (사내 절차)          시험 항목          보유 장비
고온고습 1000h        ──→     항온항습    ←──    챔버 3대
                                 ↑
                         시험법·규격 (ASTM, 사내 규격서)
                                 ↑
                          물성 (전도도, 인장강도)
```

시험 항목은 신뢰성 시험, 장비, 규격, 물성을 연결하는 기준 축임. 시험 항목이 등록되지 않은 장비는 검색 대상에서 제외됨.

## 수행 가능 장비 판정

신뢰성 시험 목록의 ‘수행 가능 장비’ 판정 순서는 다음과 같음.

1. 시험의 시험 항목 확인 (예: 항온항습)
2. 해당 시험 항목이 등록된 보유 장비 조회 (예: 챔버 3대)
3. 시험 조건(온도 85 ℃, 습도 85 %)과 장비 사양 비교
4. 조건 미충족 장비 제외 및 제외 사유 표시

시험 조건은 속성 칸에 숫자로 입력해야 판정에 반영됨. 목적 칸의 서술(예: 85도 85%)은 판정에 사용되지 않음.

## 사양 미기재 장비의 판정

장비에 해당 사양이 없으면 판정 결과는 ‘모름’으로 표시되며, ‘가능’으로 간주하지 않음. 사양 미기재 항목은 홈 화면의 ‘남은 일’에서 확인 가능.
